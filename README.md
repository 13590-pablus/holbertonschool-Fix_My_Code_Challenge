# Fix My Code Challenge

## Description
This project is part of the Holberton School curriculum. The goal of this project is to jump into existing codebases, identify bugs, and fix them without rewriting the entire code.

## Requirements
- All code will be compiled and executed on **Ubuntu 20.04 LTS**.
- Allowed text editors: `vi`, `vim`, `emacs`.
- All files should end with a new line.

## Tasks

| Task | File | Description |
| --- | --- | --- |
| **0. FizzBuzz** | `challenge/0-fizzbuzz.py` | Fixed logic for numbers divisible by 15 (`FizzBuzz`). |
| **1. Print square** | `challenge/1-print_square.js` | Fixed `parseInt` radix from 16 to 10. |
| **2. Sort** | `challenge/2-sort.rb` | Fixed array insertion index for sorted integers. |
| **3. User password** | `challenge/3-user.py` | Fixed `is_valid_password` method logic in Python `User` class. |
